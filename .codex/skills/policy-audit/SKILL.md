# 정책 감사

변경별 DoD가 아니라 저장소 전반의 반복 패턴을 측정한다. 자동 실패 판정이나 파일 수정은 하지 않는다.

각 축마다 범위, 분모, 분자, 제외 대상, 대표 예외 최대 다섯 개를 밝힌다. 적용 artifact가 없으면 `N/A`로 보고한다.

| 축 | 기대 조건 |
|---|---|
| 정본 링크 | 현재 정본·운영 문서의 상대 링크가 해석된다. |
| 상태·용어 | 현재 기준과 설정·보고가 등록된 어휘를 사용한다. |
| 계보·재현성 | 필요한 시간 필드, revision/snapshot identity, 실행 입력·환경이 있다. |
| 운영 위생 | 완료 작업의 progress, 최신 backlog, 중요 ADR이 일관된다. |
| 민감 자료 | 추적됨·대기 중 텍스트에 확인된 credential·개인정보·원본 민감 payload가 없다. |

낮은 준수율은 결정을 위한 증거이지 규칙이나 구현이 틀렸다는 증명은 아니다.
