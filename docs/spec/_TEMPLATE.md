# [기능명] 스펙

> **How.** 기능정의서(`docs/feature/`)의 결정을 어떻게 구현하는가.
> 결정·이유는 여기 다시 적지 않는다 (feature 에 있음). 여기는 구현 방법.

## 1. 대상

- 구현할 결정: `docs/feature/<기능>.md` 의 어떤 항목
- 영향 범위: 코드/스키마/외부연동

## 2. 인터페이스

- 엔드포인트 / 함수 시그니처 / 요청·응답 형태
- 에러 케이스와 응답

## 3. 데이터/스키마

- 테이블·컬럼 변경, 마이그레이션 파일 위치
- 인덱스/제약

## 4. 흐름

- 단계별 처리 (정상 / 실패 / timeout / 권한 없음)
- 외부 연동이면 호출 순서, 멱등성, 재시도 정책

## 5. 검증 계획

- build-time: 테스트 시나리오 (정상/실패/경계)
- run-time: 헬스/스모크

## 6. 참고

- 기능: `docs/feature/<기능>.md` / 룰: `.claude/rules/<관련>.md`
