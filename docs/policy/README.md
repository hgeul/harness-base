# 정책 위키 (docs/policy/)

운영·비즈니스 정책, 외부 통합 결정, 회색지대 판단 자료를 기록하는 폴더.

`.claude/rules/` 가 다 담지 못하는 영역:
- 한 도메인에서 "왜 이렇게 동작하는가 / 어느 케이스가 의도이고 어느 게 버그인가"
- 외부 시스템과의 결정사항·tradeoff·합의
- 룰로 박기엔 회색지대인 정책 노트

## 작성 가이드

- 파일명: `<도메인-키>.md`
- 코드 위치는 `path/to/File.ext:line` 형태로 표기
- 정책 변경 시 문서 상단 `최종 갱신` 일자 같이 업데이트
- **문서가 코드와 어긋났다면 코드가 정답으로 간주하고 문서를 고침** (이게 SSOT 드리프트 해소의 기본 원칙)
- 종료/흡수된 정책은 `_archive/` 로 이동

## 공유 경계

- 이 `docs/` 는 고객/프로젝트 자료다. 개인/공용 remote 로 push 금지.
- 팀 공유가 필요하면 PR 본문 발췌 또는 합의된 별도 채널로.
- 하네스 변경 이력은 `hz.sh` 평행 git-dir(remote 없음)로 로컬에만.
