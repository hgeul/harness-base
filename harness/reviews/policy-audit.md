# policy-audit 계약

변경별 DoD가 아니라 저장소 전반의 반복 정책 준수와 정책 노후화를 측정한다. 자동 실패 판정·파일 수정은 하지 않는다.

각 축마다 범위, 분모, 분자, 제외 대상, 대표 예외 최대 다섯 개를 밝힌다. 적용 artifact가 없으면 `N/A`다.

| 축 | 기대 조건 |
|---|---|
| 정본 링크 | 현재 정본·운영 문서 상대 링크 해석 |
| 상태·용어 | 현재 기준과 설정·보고가 등록 어휘 사용 |
| 계보·재현성 | 필요한 시간 필드, revision/snapshot identity, 실행 입력·환경 |
| 운영 위생 | 완료 작업 progress, 최신 backlog, 중요 ADR 일관 |
| 민감 자료 | 추적됨·대기 중 텍스트에 credential·개인정보·민감 원본 payload 없음 |

낮은 준수율은 결정을 위한 증거이지 규칙·구현 오류의 증명은 아니다.
